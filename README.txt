CIA Morocco RP — Website package
Files: index.html, style.css, app.js

PUBLISH ON A NEW GITHUB PAGES URL
1. Download and extract the ZIP on your computer.
2. Sign in to GitHub and create a NEW repository named: cia-morocco-rp
   Suggested URL: https://github.com/new
3. Choose Public, and create the repository. Do not edit or delete your old repository.
4. In the new repository, click Add file → Upload files.
5. Upload index.html, style.css, and app.js directly into the repository root.
6. Click Commit changes.
7. Open Settings → Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Select branch main and folder /(root), then Save.
10. Wait for the green check in Actions, then open:
    https://YOUR-GITHUB-USERNAME.github.io/cia-morocco-rp/

IMPORTANT
- Replace YOUR-GITHUB-USERNAME with your GitHub username.
- The website is a fictional roleplay community portal, not an official government or CIA website.
- The recruitment form prepares a text for copying; it does not transmit data to a server.
- The QCM quiz runs in the browser and calculates the score locally.
